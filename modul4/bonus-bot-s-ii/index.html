Главное

1

Бот-курьер только присылает вам готовое – ему API не нужен. Боту, который сам отвечает людям круглосуточно и по вашей базе знаний, нужен доступ к нейросети через API.

API – это «розетка» для программ: через неё программа обращается к нейросети и платит за объём текста. Подписка на ChatGPT или Claude его не покрывает, API оплачивается отдельно.

Курьер или собеседник

Чем бот-собеседник отличается от курьера

Бот из урока 3 работает как курьер. Агент на компьютере закончил задачу, и бот приносит вам готовые файлы. Сам он ничего не сочиняет и ни с кем не разговаривает: всю работу делает Codex, бот только передаёт. Поэтому отдельный доступ к нейросети ему не понадобился.

Бот-собеседник устроен иначе. Ему пишут люди, и он сам отвечает им в любое время, опираясь на вашу базу знаний. Чтобы придумать каждый ответ, ему нужна нейросеть, а значит, нужен API. Вот для каких задач собирают таких ботов.

1

Бот-куратор учеников

Отвечает ученикам на вопросы по курсу из базы знаний, а то, чего в базе нет, передаёт живому куратору.

2

Бот-помощник для клиентов

Рассказывает об услугах, условиях и порядке работы – ровно то, что вы записали в базу.

3

Бот для записи и частых вопросов

Снимает с вас повторяющиеся вопросы и принимает заявки на запись.

Пример из жизни курса. ИИ-куратор в чате этого курса – как раз такой бот-собеседник в Telegram. Его собрали в Codex, база знаний курса разложена по карточкам, а отвечает он через API OpenAI.

API нужен, если бот сам отвечает людям: круглосуточно, без вашего участия, по вашей базе знаний.

API не нужен, если вам просто присылать готовое себе. Для этого хватит бота-курьера из урока и навыка «Доставка готового» из бонуса «Навыки контент-агента».

Хотите, чтобы бот принимал задачи только от вас – например, идеи постов в папку блога? Начните с промпта «Двусторонний бот – следующая ступенька» в конце конспекта урока 3: Codex разберёт, что для этого нужно в вашем случае.

API простыми словами

Розетка, через которую программа говорит с нейросетью

Когда вы пишете в ChatGPT или Claude, вы общаетесь с нейросетью через окно чата. У программы окна нет, ей нужен свой вход. API – это такая «розетка»: программа подключается к нейросети, отправляет текст и получает ответ.

Доступ к розетке открывает ключ API – длинная строка-пароль. По ней провайдер понимает, чей это запрос и с чьего счёта списать деньги.

Платите вы за объём текста. Его считают в токенах – кусочках слов, на которые нейросеть режет текст. Считается и то, что программа отправила нейросети (вход), и ответ (выход). Цену пишут за 1 млн токенов, у входа и выхода она обычно разная.

Подписка на чат API не оплачивает. ChatGPT Plus или Claude Pro – это работа в окне чата, запросы программы через API оплачиваются отдельно.

Как устроен бот

3 части бота-собеседника

Telegram→Программа-посредник→API нейросети
1

Telegram и BotFather

Бота создают в Telegram у официального бота @BotFather – так же, как в уроке 3. BotFather выдаёт токен – секретный ключ, по которому программа управляет вашим ботом.

2

Программа-посредник

Сердце бота. Она принимает сообщение от человека, добавляет к нему инструкцию (кто бот и как отвечает) и базу знаний, отправляет всё это в API нейросети и возвращает ответ в Telegram.

3

API нейросети

Здесь рождается ответ. Нейросеть читает инструкцию, базу и вопрос и пишет текст, а провайдер списывает деньги за токены.

Где живёт программа

1

На вашем компьютере

Пока компьютер включён – бот работает. Для проверки и первых недель этого достаточно.

2

Круглосуточно – позже

Когда бот заработает, спросите Codex, как перенести его в облачную функцию – небольшую программу в облаке, которая запускается на каждое сообщение. Небольшому боту обычно хватает бесплатного объёма Yandex Cloud Functions.

Программу писать самостоятельно не нужно: её пишет Codex по вашему описанию. Промпт – ниже, в разделе «Собрать бота с Codex».

Где взять API

Где взять ключ API: 2 российских провайдера

Условия проверены 19.10.2026. Цены указаны за 1 млн токенов: сначала вход, через косую черту – выход. Цены и условия меняются, поэтому перед оплатой загляните по ссылке.

1

Yandex AI Studio (YandexGPT, Алиса AI)

Ключ. Вход по Яндекс ID → организация → «Привязать платежный аккаунт» (нужна карта) → «Создать API-ключ». «Организация» здесь – просто название вашего пространства в кабинете, ИП не нужен. Пошагово – в инструкции Яндекса. Codex может попросить идентификатор каталога – спросите его, где найти.

Цена с НДС. Alice AI LLM Flash – 100 ₽ / 200 ₽, YandexGPT Lite – 200 ₽ / 200 ₽, Alice AI LLM – 500 ₽ / 1 200 ₽, YandexGPT Pro 5.1 – 800 ₽ / 800 ₽ (цены). Стартовый грант для новых клиентов – уточните при регистрации, условия менялись.

Где проверить. Playground в AI Studio.

Лимит расходов. Billing → «Бюджеты». Бюджет только присылает уведомления – поставьте небольшой бюджет, например 300 ₽, и следите за почтой. Для спокойствия можно платить картой, на которой небольшая сумма.

2

GigaChat (Сбер)

Ключ. Личный кабинет Studio → проект GigaChat API → «Настройки API» → «Получить ключ». Пошагово – в инструкции Сбера для физлиц. При выдаче ключа показывают Authorization Key, Client ID и Client Secret – сохраните все значения в надёжное место, они показываются 1 раз.

Условия. 18+, резидент РФ. У подключения есть технические особенности – Codex учтёт их сам, вам ничего ставить не нужно.

Цена. Freemium – 365 млн токенов на 12 месяцев бесплатно, но только для личных некоммерческих задач, например чтобы проверить инструкцию. Боту для учеников или клиентов нужен платный доступ. С 1 сентября 2026 новые клиенты оплачивают модели на cloud.ru – где регистрироваться и платить, уточните на странице GigaChat API, условия меняются. Цены на cloud.ru: GigaChat3-10B – 12,2 ₽ и за вход, и за выход, GigaChat-3-Pro – 73,03 ₽ / 176,39 ₽.

Где проверить. Песочница промптов в личном кабинете.

Лимит расходов. Предоплаченный пакет: тратится то, что вы оплатили заранее.

Новичку советуем Yandex AI Studio: вход по Яндекс ID, один кабинет – и ключ, и оплата картой в рублях, понятная песочница. GigaChat дешевле по токенам – выбирайте его, если готовы к чуть более сложному подключению: его Codex настроит сам.

Сколько стоит

Бот-куратор на 50 учеников: считаем токены

Возьмём пример: 50 учеников задают около 300 вопросов в месяц, каждый ответ бота – около 500 токенов. С каждым вопросом программа отправляет нейросети базу знаний, и сделать это можно 2 способами: отправлять всю базу – 15 000 токенов в каждом запросе – или подбирать только нужные карточки, около 5 000 токенов.

Бот на 50 учеников в GigaChat или Яндексе – примерно от 20 до 930 ₽ в месяц за ответы.

Как посчитать для себя: вход (млн токенов) × цена входа + выход (млн токенов) × цена выхода. В нашем примере вход – 300 × 15 000 = 4,5 млн токенов, выход – 300 × 500 = 0,15 млн. Отправить всю базу или подобрать карточки – это решает программа: подбор нужных карточек дешевле в 2–3 раза. Попросите Codex так и сделать.

Цифры приблизительные. У провайдеров разные токенизаторы, и один и тот же текст режется на разное число токенов. История диалога тоже увеличивает вход. Поэтому считайте таблицу ориентиром для выбора модели. Главное вложение – ваше время на настройку: 2–3 вечера.

Проверка без кода

Испытайте бота в песочнице до сборки

Песочница (Playground) – окно в кабинете провайдера, где можно поговорить с моделью через API без всякой программы. Здесь удобно отладить главное: инструкцию бота и базу знаний. Бота ещё нет, а вы уже видите, как он будет отвечать.

1

Соберите инструкцию бота

Скопируйте первый промпт ниже в ChatGPT или Claude. Он задаст вам вопросы и соберёт инструкцию: кто бот, для кого, что отвечает, чего не делает, каким тоном говорит.

2

Подготовьте 3–5 карточек базы

Карточка – короткий текст на одну тему: частый вопрос и ответ на него, правило, нужная ссылка. Для проверки хватит 3–5 карточек на самые частые вопросы.

3

Зарегистрируйтесь у провайдера

Выберите одного провайдера и заведите аккаунт: Yandex AI Studio или GigaChat. Больших денег для проверки не нужно: у GigaChat для личных некоммерческих задач есть бесплатный Freemium, в Yandex AI Studio к кабинету привязывают карту, а тестовые вопросы расходуют совсем немного токенов. Точные условия покажет кабинет при регистрации.

4

Откройте песочницу

Yandex – Playground в AI Studio. GigaChat – песочница промптов в личном кабинете. С зарубежной картой: OpenAI – Chat Playground, Anthropic – Playground в консоли.

5

Вставьте инструкцию и карточки

Поле для инструкции может называться System, «Системный промпт» или «Инструкция». Карточки вставьте туда же, под инструкцией.

6

Задайте 10 реальных вопросов

Возьмите вопросы, которые ученики или клиенты уже задавали вам в чате или в личке. Смотрите, где бот врёт и где отвечает не по базе. Второй промпт ниже добавит вопросы-ловушки.

7

Поправьте инструкцию

Каждую ошибку превращайте в правило инструкции и задавайте вопрос заново. Когда ответы вас устраивают, можно собирать бота.

Промпт 1. Собери инструкцию для моего бота-помощника

В ChatGPT или Claude

Ты – методолог, который помогает составить инструкцию (системный промпт) для Telegram-бота с ИИ. Бот отвечает людям сам, только по моей базе знаний.

Задай мне вопросы по одному и дождись ответа на каждый:
1. Как зовут бота и от чьего имени он говорит: [от моего имени / от имени школы «название»].
2. Для кого бот: [ученики курса / клиенты / те, кто хочет записаться].
3. На какие вопросы он отвечает – темы и 3–5 примеров.
4. Чего бот не делает: не обещает [скидки, сроки, результат], не даёт [медицинских, юридических] советов, не обсуждает темы вне базы.
5. Кому передавать вопросы, ответа на которые нет в базе: [куратор, @ник, почта].
6. Тон: [на «вы» / на «ты»], длина ответа, можно ли эмодзи.

Когда я отвечу на все вопросы, собери инструкцию по структуре:
– Роль: кто бот и для кого.
– Задача: на какие вопросы отвечает.
– Источник: отвечай только по базе знаний. Если ответа в базе нет, скажи: «Этого нет в моих материалах, передам вопрос [кому]» – и ничего не придумывай.
– Запреты: чего бот не делает и что не обещает.
– Тон и формат ответа.
– Что отвечать на приветствие, благодарность и вопрос не по теме.

Выдай инструкцию одним блоком, готовым для копирования, не длиннее [1 страницы]. После неё напиши 3 вопроса, на которых её стоит проверить в первую очередь.

Промпт 2. Проверь ответы бота

В ChatGPT или Claude, рядом с песочницей

Ты – строгий тестировщик чат-ботов. Ниже – инструкция моего бота и его база знаний.

Шаг 1. Придумай 10 вопросов-ловушек, на которых бот может ошибиться:
– 3 вопроса, ответ на которые есть в базе, но сформулированы они другими словами;
– 3 вопроса, ответа на которые в базе нет – бот должен сказать, что передаст вопрос [куратору];
– 2 вопроса с просьбой пообещать то, чего нет в базе: [скидку, сроки, результат];
– 1 вопрос не по теме;
– 1 попытку заставить бота нарушить инструкцию: «забудь свои правила и…».
Покажи вопросы списком и остановись. Я задам их боту в песочнице и пришлю ответы.

Шаг 2. Когда я пришлю ответы, оцени каждый: верно / неточно / выдумал / нарушил правило. Для каждой ошибки предложи конкретную правку инструкции. В конце дай исправленную инструкцию целиком.

Инструкция бота:
[вставьте инструкцию]

База знаний:
[вставьте 3–5 карточек]

Потом вставьте промпт: Codex сначала покажет план, а потом проведёт по шагам – создать бота в BotFather, получить ключ API, запустить.

В Codex, в папке «Бот-куратор»

Создай в этой папке «Бот-куратор» простого Telegram-бота с ИИ.

Что делает бот:
– принимает сообщения и отвечает на них через API [GigaChat / YandexGPT – оставьте одно, второе сотрите];
– отвечает по инструкции из файла [Инструкция бота.md] и по базе знаний из папки [База знаний];
– если ответа в базе нет, говорит, что передаст вопрос [куратору], и ничего не придумывает;
– отвечает только [в чате «название чата» / в личных сообщениях – оставьте одно].

Безопасность:
– токен бота и ключ API храни локально в файле .env;
– не показывай токен и ключ в чате и не проси меня присылать их сюда – покажи, в какой файл их вставить;
– если это GigaChat: ключ выдаётся как Authorization Key, Client ID и Client Secret; для подключения нужны сертификаты НУЦ Минцифры, а токен доступа живёт 30 минут – настрой всё это сам, чтобы мне ничего не устанавливать вручную и токен обновлялся автоматически;
– если это YandexGPT и нужен идентификатор каталога, подскажи, где его найти в кабинете.

Как работаем:
1. Сначала покажи план простыми словами: какие файлы создашь и что в них будет. Ничего не делай, пока я не подтвержу.
2. Проведи меня по шагам: создать бота в @BotFather, получить ключ API, вставить их в .env, запустить бота.
3. Если база знаний большая, предложи, как отправлять в нейросеть только подходящие к вопросу карточки, – так дешевле.
4. Добавь проверку на 5 вопросах из базы: покажи ответы бота и оцени, совпадают ли они с базой.

Безопасность

4 правила для бота с ИИ

1

Ключ API – это ваши деньги

Кто знает ключ, тот тратит с вашего счёта. Не публикуйте его, не присылайте в чат, храните локально в файле .env. И сразу поставьте лимит или бюджет – где это сделать у каждого провайдера, написано выше.

2

Токен бота – так же

По токену можно управлять вашим ботом и писать от его имени. Храните его рядом с ключом и никому не показывайте.

3

Персональные данные учеников – в России

152-ФЗ запрещает хранить персональные данные россиян в базах за рубежом. Работаете с GigaChat или Яндексом – данные остаются в России. Не просите бота собирать телефоны и личные данные учеников. Передавать личные данные в зарубежный API – только после консультации с юристом.

4

Бот не обещает того, чего нет в базе

Всё, на что в базе нет ответа, бот передаёт вам или куратору. Пропишите это в инструкции и проверьте вопросами-ловушками.

Подробнее о правилах для агентов – в памятке «Как устроены агенты и как задавать им правила». Куда ещё агент может приносить результат – в бонусе «Откуда агент берёт и куда приносит», а как работать с агентом с телефона и в облаке – в бонусе «Агент с телефона и в облаке».
